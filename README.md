# 🔍 Product Review Sentiment Analyser — Streamlit App

A web app that classifies Amazon product reviews as **Positive**, **Neutral**, or **Negative** using TF-IDF + Machine Learning.

---

## 📁 Project Structure

```
project/
├── streamlit_app.py              # Streamlit application  ← deployment file
├── sentiment_analysis.py         # ML pipeline: training, inference helpers
├── requirements.txt              # Python dependencies
├── Amazon_Reviews.csv            # Raw dataset
├── saved_models/
│   ├── best_model.pkl            # Best trained classifier
│   ├── tfidf_vectorizer.pkl      # Fitted TF-IDF vectorizer
│   ├── feature_selector.pkl      # Feature selector
│   ├── label_encoder.pkl         # Label encoder
│   └── metadata.json             # Model metrics (accuracy, F1, etc.)
└── plots/                        # Training visualisation PNGs
    └── *.png
```

> **Important:** Run `sentiment_analysis.py` first to generate `saved_models/` and `plots/` before launching the app.

## 🚀 Local Setup & Run

### 1. Clone / download the repo

```bash
git clone https://github.com/your-username/sentiment-analyser.git
cd sentiment-analyser
```

### 2. Create a virtual environment (recommended)

```bash
python -m venv venv
source venv/bin/activate        # macOS / Linux
venv\Scripts\activate           # Windows
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Train the model & generate artifacts

```bash
python sentiment_analysis.py Amazon_Reviews.csv
```

This saves everything into `saved_models/` and `plots/`.

### 5. Launch the app

```bash
streamlit run streamlit_app.py
```

Open [http://localhost:8501](http://localhost:8501) in your browser.

---

## ☁️ Deploy on Streamlit Community Cloud (Free)

1. Push the project to a **public GitHub repository** (include `saved_models/` and `plots/`).
2. Go to [share.streamlit.io](https://share.streamlit.io) → **New app**.
3. Connect your GitHub repo and set:
   - **Main file path:** `streamlit_app.py`
   - **Python version:** 3.11
4. Click **Deploy** — Streamlit will auto-install from `requirements.txt`.

> If `.pkl` files exceed 100 MB, use [Git LFS](https://git-lfs.github.com/) to track them.

## 🖥️ App Features

| Tab | Description |
|-----|-------------|
| **Single Review** | Paste any review → get sentiment label + confidence scores |
| **Batch Analysis** | Upload a CSV, pick the text column, download predictions |
| **Saved Plots** | View all training visualisations generated by the pipeline |

The sidebar shows the best model name and its Accuracy, F1, Precision, and Recall from `metadata.json`.

## 🤖 ML Pipeline Summary

```
Raw Review Text
      ↓
Text Cleaning & Preprocessing  (in sentiment_analysis.py)
      ↓
TF-IDF Vectorisation + Feature Selection
      ↓
Best Classifier  (saved to saved_models/best_model.pkl)
      ↓
Sentiment Label  →  Positive | Neutral | Negative
```
